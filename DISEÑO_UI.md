# AutoGest — diseño del frontend

Se cambió el lenguaje visual del laboratorio previo: de una interfaz editorial verde para una tienda/escuela de música a un **panel automotriz** con barra lateral azul marino, acentos turquesa, estados ámbar, fuentes Manrope y DM Sans, y tarjetas de métricas.

- **Cabecera:** identidad `AutoGest LAB`, estado de Neon y recarga del diagnóstico.
- **Navegación izquierda:** cinco secciones del temario, descripción del entorno y botón de preparación.
- **Catálogo central:** búsqueda de ejercicios y fichas con el código `S/J/A/V/T`.
- **Área principal:** tres indicadores, explicación de la práctica, código SQL copiable, parámetros y tabla de resultados reales.
- **Guía contextual:** instrucciones en un diálogo desplegable.
- **Seguridad de interacción:** el botón de preparar exige confirmación; la ejecución está desactivada si la BD no está lista; demostraciones de triggers revertidas.

Paleta: azul marino `#10283C`, turquesa `#0A9291`, ámbar `#F2AD59`, fondo `#F0F4F7`. Se diseñó para desktop y se adapta a pantallas pequeñas con columnas reordenadas.
